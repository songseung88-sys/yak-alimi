# 약 알리미 — 비공개 테스트용 프리미엄 모드

기준: 2026-09-28

## 목적
비공개 테스트 참가자가 결제 절차 없이 앱의 전체 기능을 충분히 시험할 수 있도록 테스트 전용 빌드에서는 프리미엄 권한을 자동 활성화한다.

## 테스트판 동작
- 광고 표시 안 함
- 약·영양제 여러 항목 등록 가능
- 프리미엄 기능 전체 사용 가능
- 실제 Google Play 구매 불필요
- 설정 > 프리미엄 영역에 `테스트 프리미엄 활성화됨` 표시
- 구매/이전 구매 복구 버튼은 테스트판에서 표시하지 않음

## 프로덕션판과의 분리
테스트 프리미엄 패치는 `yak_alimi_closedtest_work`라는 별도 작업 복사본에만 적용한다.

일반 프로덕션 작업본 `yak_alimi_v21_work`에는 `CLOSED_TEST_PREMIUM = true`가 들어가지 않도록 CI에서 검증한다. 따라서 테스트판을 그대로 프로덕션으로 승격하지 않고, 실제 출시 시에는 테스트 프리미엄이 없는 프로덕션 빌드를 새 versionCode로 생성한다.

## 결제 기능 테스트
일반 테스터에게는 결제를 요구하지 않는다. Google Play Billing의 실제 구매/취소/이전 구매 복구 흐름은 별도의 개발자·라이선스 테스트 계정으로 검증한다.

## 비공개 테스트 종료 후
테스터가 이후 일반 출시 빌드로 업데이트하면 테스트용 무료 프리미엄 권한은 사라진다. 실제 프리미엄을 계속 사용하려면 정식 상품을 구매해야 한다.

## 배포 원칙
- 비공개 테스트 트랙: `closedtest` AAB 사용
- 프로덕션 트랙: `production` AAB 사용
- closedtest AAB를 그대로 프로덕션으로 승격하지 않음
- 프로덕션 전환 시 versionCode 증가
