## 3. 전체화면 인텐트 (USE_FULL_SCREEN_INTENT) 선언

### 사용 목적
`알람 설정 / 시간에 민감한 복용 알림`

### 설명 문안
`약 알리미의 핵심 기능은 사용자가 미리 지정한 약·영양제 복용 시각에 알림을 제공하는 것입니다. 사용자가 직접 설정한 복용 알림이 도착했을 때, 잠금화면에서도 즉시 확인하고 복용 여부를 처리할 수 있도록 전체화면 알림을 선택적으로 사용합니다. 광고, 프로모션 또는 사용자가 설정하지 않은 콘텐츠에는 전체화면 인텐트를 사용하지 않습니다.`

### 권한이 허용되지 않은 경우
`Android 14 이상에서는 전체화면 알림 권한 상태를 확인하며, 권한이 없으면 일반 알림으로 동작하고 사용자가 원할 때 설정 화면에서 직접 권한을 허용할 수 있도록 안내합니다.`

### 심사 시 강조할 포인트
- 알림 시각은 사용자가 직접 설정함
- 약·영양제 복용이라는 시간 민감한 알림에만 사용함
- 광고/마케팅 목적으로 사용하지 않음
- 사용자가 권한을 거부해도 앱이 일반 알림으로 계속 작동함
- 권한 상태를 Android API로 확인하고 재허용 경로를 제공함

## 4. Data safety 입력 방향

> 앱 자체의 약·영양제 이름, 복용 일정, 복용 기록, 재고는 개발자 서버로 전송되지 않습니다. 다만 무료 버전의 Google Mobile Ads SDK 때문에 `데이터를 수집/공유하지 않음`으로 단순 답변하면 안 됩니다.

### 전체 질문
- 앱 또는 포함된 SDK가 사용자 데이터를 수집하거나 공유하는가? → `예`
- 모든 사용자 데이터가 전송 중 암호화되는가? → Google Mobile Ads SDK 전송은 TLS 사용. 최종 양식에서는 앱에 포함된 모든 네트워크 처리 기준으로 확인 후 답변.
- 사용자가 데이터 삭제를 요청할 방법이 있는가? → 앱 자체 복용 데이터는 로컬 데이터이므로 앱 내 삭제, Android 앱 데이터 삭제 또는 앱 제거로 삭제 가능. 개발자 서버에는 복용 데이터가 없음.

### Google Mobile Ads SDK 때문에 선언을 검토할 데이터 유형

#### 대략적인 위치
- 근거: IP 주소가 대략적인 위치 추정에 사용될 수 있음
- 목적 후보: 광고 또는 마케팅 / 분석 / 사기 방지·보안·규정 준수

#### 앱 활동 — 사용자 상호작용
- 예: 앱 실행, 탭, 광고 상호작용 등
- 목적 후보: 광고 또는 마케팅 / 분석 / 사기 방지

#### 앱 정보 및 성능 — 진단
- 예: 앱/SDK 성능 및 진단 정보
- 목적 후보: 분석 / 사기 방지·보안·규정 준수

#### 기기 또는 기타 ID
- 예: 광고 ID, App Set ID 등
- 목적 후보: 광고 또는 마케팅 / 분석 / 사기 방지

### 건강 데이터
`사용자가 입력한 약·영양제 이름, 복용 시간, 복용 기록, 재고 정보는 사용자 기기에만 저장되며 개발자 서버나 Google Mobile Ads에 전달하지 않습니다.`

### 최종 제출 직전 확인
