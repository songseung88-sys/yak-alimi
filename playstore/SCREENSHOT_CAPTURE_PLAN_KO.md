# 약 알리미 Google Play 스크린샷 촬영 계획

## 원칙
- 실제 앱에서 제공하는 기능만 보여준다. 기능을 과장하거나 존재하지 않는 동작을 표현하지 않는다.
- 개인 복용 정보가 보이지 않도록 촬영용 샘플 데이터를 사용한다.
- ‘약 알리미’ 브랜드명은 유지하되 약뿐 아니라 영양제도 관리할 수 있다는 점을 첫 화면부터 자연스럽게 전달한다.
- 한국어 스크린샷을 우선 제작하고, 필요할 경우 같은 구도로 영어 등 다른 언어판을 추가한다.
- 상태바의 개인 알림, 전화번호, 메신저 내용 등은 노출되지 않도록 정리한다.
- 스토어용 후처리본에서는 테스트 광고 영역을 제거하고 앱 화면과 마케팅 캡션을 명확히 구분한다.

## 권장 샘플 데이터
- 비타민 D — 오전 8:00
- 오메가3 — 오후 1:00
- 유산균 — 오후 9:00
- 필요하면 일반 의약품 예시 1개를 함께 두어 ‘약 + 영양제’ 모두 관리 가능하다는 점을 보여준다.
- 재고는 30개, 저재고 기준은 5개 정도로 설정한다.

## 권장 6장 구성

### 1. 오늘 화면 — 핵심 가치
보여줄 화면: 오늘 복용할 약·영양제, 복용 상태, 다음 복용 시간과 남은 수량이 한눈에 보이는 상태

추천 캡션: `약·영양제 복용 상태를 한눈에`

### 2. 잠금화면 전체화면 알림
보여줄 화면: 복용 시간이 되었을 때 뜨는 전체화면 복용 알림

추천 캡션: `잠금화면에서 바로 복용 완료`

주의: 실제 기기와 권한에서 정상 작동하는 화면을 기준으로 한다.

### 3. 약·영양제 추가 / 알림 설정
보여줄 화면: 이름, 받은 개수, 복용 횟수, 알림 시간, 알림 방식, 복용 요일을 설정하는 화면

추천 캡션: `약·영양제 추가와 알림 설정을 간단하게`

### 4. 복용 기록 / 히스토리
보여줄 화면: 날짜별 복용 완료 기록

추천 캡션: `복용 기록을 날짜별로 확인`

### 5. 재고 관리
보여줄 화면: 남은 수량과 재고 추가 화면

추천 캡션: `약·영양제 남은 수량까지 관리`

### 6. 언어 지원 / 프리미엄
보여줄 화면: 6개 언어 선택 화면과 프리미엄 안내

추천 캡션: `6개 언어 지원, 필요하면 프리미엄으로`

프리미엄 혜택에는 `여러 약·영양제 등록`을 사용한다. 가격이 들어가는 경우에는 Google Play에서 조회된 실제 현지 가격과 일치해야 한다.

## 촬영 순서
1. 비타민 D, 오메가3 등 샘플 데이터 입력
2. 오늘 화면 촬영
3. 복용 알림 시간을 2~3분 뒤로 설정해 잠금화면 알림 촬영
4. 약·영양제 추가/설정 화면 촬영
5. 일부 항목을 복용 완료 처리한 뒤 기록 화면 촬영
6. 재고 수량을 조정해 재고 화면 촬영
7. 언어 선택 및 프리미엄 화면 촬영

## 후처리 계획
Google Play용 마케팅 버전에서는 실제 앱 화면을 중심에 두고 화면 바깥에만 통일된 배경과 짧은 캡션을 추가한다. 캡션은 언어별로 별도 제작한다. 테스트 광고, 개인 상태바 정보 등 스토어 홍보와 무관한 요소는 최종 자산에서 노출하지 않는다.

## 제출 전 확인
- 최소 2장 이상 등록
- 실제 앱 동작과 스크린샷 내용 일치
- 개인정보·실제 복용 정보 미노출
- ‘약’과 ‘영양제’ 모두 사용할 수 있다는 점이 최소 2장의 자산에서 명확히 드러남
- 가격이 들어간 화면은 실제 Play 현지 가격과 일치
- 캡션이 화면의 중요한 UI를 가리지 않음
