# 약 알리미 개인정보처리방침 공개 절차

개인정보처리방침 파일은 `docs/privacy-policy.html`에 준비되어 있다.

## GitHub Pages 최초 설정
1. GitHub 저장소 `songseung88-sys/yak-alimi`에서 **Settings**를 연다.
2. 왼쪽 메뉴에서 **Pages**를 선택한다.
3. **Build and deployment > Source**를 **Deploy from a branch**로 선택한다.
4. Branch는 **main**, 폴더는 **/docs**를 선택한다.
5. **Save**를 누른다.

게시가 완료되면 개인정보처리방침 주소는 다음과 같다.

`https://songseung88-sys.github.io/yak-alimi/privacy-policy.html`

## 앱 연결 상태
V3.0.3 빌드는 설정 > 개인정보처리방침에서 위 주소를 외부 브라우저로 연다. 브라우저를 열 수 없는 경우에만 앱 내 간단한 개인정보 안내를 대신 표시한다.

## Google Play Console
Play Console의 개인정보처리방침 URL에도 위 주소를 동일하게 입력한다.
