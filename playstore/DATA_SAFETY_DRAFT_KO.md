# 약 알리미 Data safety 초안

> 이 문서는 Play Console 입력 전 검토용 초안입니다. Google SDK 동작과 앱 설정이 바뀌면 다시 확인해야 합니다.

## 앱 자체 복약 데이터
- 약 이름, 복용 시간, 복용 기록, 재고: 사용자 기기에만 저장
- 자체 서버 전송: 없음
- 자체 계정/클라우드 DB: 없음

따라서 복약 데이터 자체는 앱 개발자 서버로 수집하지 않습니다.

## Google Mobile Ads SDK 때문에 고려할 데이터
Google Mobile Ads SDK 25.5.0 기준으로 Google은 광고, 분석, 사기 방지 목적을 위해 다음 데이터를 자동 수집/공유할 수 있다고 안내합니다.
- IP 주소(대략적 위치 추정에 사용될 수 있음)
- 사용자 제품 상호작용(앱 실행, 탭 등)
- 진단 정보(앱/SDK 성능 관련)
- 기기 및 계정 식별자(Android 광고 ID, app set ID 등)

이 데이터는 전송 중 TLS로 암호화됩니다.

## 권장 Play Console 입력 방향
- 데이터 수집 여부: 예 (광고 SDK 때문에)
- 데이터 공유 여부: 예 (광고 SDK 처리에 해당)
- 목적: 광고 또는 마케팅, 분석, 사기 방지/보안/규정 준수 등 실제 SDK 동작에 맞게 선택
- 대략적 위치: IP 주소 기반 처리 여부를 최신 AdMob 문서 기준으로 반영
- 기기 또는 기타 ID: 광고 ID/app set ID 관련 처리 반영
- 앱 활동/사용자 상호작용: 광고 SDK 상호작용 처리 반영
- 앱 정보 및 성능/진단: SDK 진단 처리 반영
- 복약/건강 데이터: 앱 서버 또는 광고 SDK로 전송하지 않음. 광고 타겟팅에 사용하지 않음
- 전송 중 암호화: 예 (해당 Google SDK 전송)

## Google Play Billing
프리미엄 결제는 Google Play Billing을 사용합니다. 신용카드 번호 같은 결제 수단 정보는 앱이 직접 수집/저장하지 않습니다. 구매 상태 확인에 필요한 정보는 Google Play를 통해 처리됩니다.

## 출시 직전 다시 확인할 항목
1. 실제 적용된 Mobile Ads SDK 버전
2. UMP 및 광고 개인화 설정
3. Play Billing 버전과 사용 방식
4. 사용자 의견 보내기 기능에서 앱이 직접 데이터를 서버로 전송하는지 여부
5. 개발자 응원하기 링크의 실제 서비스와 그 서비스의 데이터 처리
