# 약 알리미 Google Play 출시 체크리스트

## A. Google Play Console
- [ ] Google Play 개발자 계정 준비
- [ ] 앱 생성: 이름 `약 알리미`, 기본 언어 한국어, 앱, 무료
- [ ] 패키지명 확인: `com.yakalimi.app`
- [ ] Play App Signing 사용 설정
- [ ] 앱 카테고리 및 연락처 이메일 입력
- [ ] 개인정보처리방침 공개 URL 입력
- [ ] 스토어 등록정보 입력 및 아이콘/스크린샷 업로드

## B. 건강 앱 정책
- [ ] 정책 > 앱 콘텐츠 > 건강 앱 선언 작성
- [ ] `의료 > 약물 및 치료 관리 (Medication and Treatment Management)` 선택
- [ ] 앱이 의료기기가 아님을 정확히 선언
- [ ] 스토어 설명에 다음 취지의 고지 유지: `의료기기가 아니며 어떠한 의학적 상태도 진단, 처치, 치료 또는 예방하지 않습니다.`
- [ ] 의료적 판단은 의사·약사 등 의료 전문가와 상담하도록 안내

## C. Data safety
- [ ] 앱 자체 복약 데이터가 서버로 전송되지 않음을 반영
- [ ] Google Mobile Ads SDK가 처리하는 데이터 항목을 최신 Google SDK 문서 기준으로 선언
- [ ] Google Play Billing SDK 관련 처리를 최신 Google 문서 기준으로 선언
- [ ] 광고 목적 데이터 처리와 사용자 동의(해당 지역)를 정확히 표시
- [ ] 개인정보처리방침과 Data safety 답변이 일치하는지 검토

## D. AdMob
- [ ] AdMob 계정 준비
- [ ] Android 앱 `약 알리미` 등록
- [ ] 실제 AdMob App ID 발급
- [ ] 실제 Anchored Adaptive Banner 광고 단위 ID 발급
- [ ] 개발/내부 테스트에서는 Google 테스트 광고 또는 테스트 기기만 사용
- [ ] 프로덕션 빌드 전 Google 테스트 광고 ID 제거
- [ ] UMP 메시지/동의 설정 확인

## E. 프리미엄 일회성 구매
- [ ] Play Console > 수익 창출 > 제품에서 일회성 제품 생성
- [ ] Product ID: `premium_unlock`
- [ ] 유형: 비소비성 1회 구매(광고 제거 + 여러 약 등록)
- [ ] 가격 결정
- [ ] 라이선스 테스트 계정 추가
- [ ] 내부 테스트 트랙에서 실제 구매 및 구매 복원 검증

## F. 전체화면 알림
- [ ] `USE_FULL_SCREEN_INTENT`가 약 알림이라는 핵심 기능에 필요한지 설명 준비
- [ ] Play Console의 전체화면 인텐트 관련 선언/검토 항목이 표시되면 `알람 설정` 용도에 맞게 작성
- [ ] Android 14+에서 `canUseFullScreenIntent()` 기반 권한 상태 확인 유지
- [ ] 권한이 해제된 경우 사용자에게 재허용 경로 제공

## G. 배포 파일
- [ ] Play Store 업로드용 AAB 생성
- [ ] AAB를 최종 upload key로 서명
- [ ] release versionCode를 매 출시마다 증가
- [ ] 서명키/업로드키 안전하게 별도 백업
- [ ] GitHub 공개 저장소에 개인키·비밀번호를 업로드하지 않음

## H. 테스트 순서
- [ ] 내부 테스트 트랙 업로드
- [ ] Play Store에서 실제 설치
- [ ] 무료 1약 제한 확인
- [ ] 배너 광고 확인
- [ ] 프리미엄 구매 후 광고 제거 확인
- [ ] 구매 후 여러 약 등록 확인
- [ ] 삭제/재설치 후 구매 복원 확인
- [ ] 복약 알림, 재알림, 잠금화면 전체화면 알림 확인
- [ ] 6개 언어 전환 확인
- [ ] 업데이트 후 기존 복약 기록 유지 확인

## 출시 전에 필요한 사용자 값
1. Play Console 연락처/지원 이메일
2. AdMob App ID
3. AdMob 배너 광고 단위 ID
4. `premium_unlock` 판매 가격
5. `개발자 응원하기`에 사용할 링크 또는 방식
6. 개인정보처리방침을 공개할 최종 URL
