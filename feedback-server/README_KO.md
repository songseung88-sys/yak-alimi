# 약 알리미 앱 내부 의견 보내기 — Google Apps Script 배포

앱은 메일 앱을 열지 않고 자체 의견 작성창에서 메시지를 작성합니다. 실제 전송은 HTTPS로 배포된 Google Apps Script 웹 앱이 받아 `songseung88@hanmail.net`으로 전달합니다.

## 1. Apps Script 프로젝트 만들기
1. https://script.google.com 에 로그인합니다.
2. **새 프로젝트**를 만듭니다.
3. 기본 `Code.gs` 내용을 모두 지우고 이 폴더의 `Code.gs` 내용을 붙여넣습니다.
4. 저장합니다.

## 2. 웹 앱으로 배포
1. 우측 상단 **배포 → 새 배포**를 선택합니다.
2. 유형은 **웹 앱**을 선택합니다.
3. 실행 사용자는 **나(Me)** 로 둡니다.
4. 액세스 권한은 외부 앱에서 POST할 수 있도록 **모든 사용자(Anyone)** 로 설정합니다.
5. 배포하면서 요구되는 권한을 승인합니다. `MailApp.sendEmail()` 사용 때문에 메일 전송 권한 승인이 필요합니다.
6. 배포 후 발급되는 `https://script.google.com/macros/s/.../exec` 형태의 **웹 앱 URL**을 복사합니다.

## 3. Android 앱에 연결
발급된 웹 앱 URL을 ChatGPT에 전달하면 `BuildConfig.FEEDBACK_ENDPOINT`에 production/closed-test 공통으로 연결합니다. URL 자체는 비밀키가 아니므로 앱에 포함되어도 되지만, Apps Script 측 일일 수신 제한과 메시지 길이 제한은 유지합니다.

## 4. 동작 방식
- 앱에서 선택하는 유형: 버그 제보 / 개선 제안 / 기타
- 메시지 최대 3,000자
- 앱은 약·영양제 이름, 복용 일정, 복용 기록, 재고 정보를 자동 첨부하지 않습니다.
- 서버는 메시지와 유형, 접수 시각만 메일로 전달합니다.
- 서버 코드에는 전체 일일 수신 한도 100건이 설정돼 있습니다.

## 5. 배포 후 테스트
앱의 **설정 → 의견 보내기**에서 짧은 테스트 메시지를 전송한 뒤 `songseung88@hanmail.net` 수신 여부를 확인합니다. 실패하면 Apps Script의 **실행 기록**에서 오류를 확인합니다.
