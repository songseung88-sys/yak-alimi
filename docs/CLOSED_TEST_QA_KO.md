# 약 알리미 비공개 테스트 QA 계획

최종 수정: 2026-09-27

## 1. 테스트 목표
출시 전 실제 Android 기기에서 다음 핵심 동작을 확인한다.

- 복약 알림이 지정한 시간에 정확히 표시되는지
- 잠금화면/화면 꺼짐 상태에서도 필요한 알림을 놓치지 않는지
- 복용 완료 기록과 재고 차감이 정확한지
- 앱 종료, 재부팅, 시간대 변경 후에도 알림이 유지되는지
- 무료/프리미엄 경계가 사용자를 혼란스럽게 하지 않는지
- 개인정보처리방침, 의견 보내기, 이전 구매 복구 등 설정 메뉴가 정상 동작하는지
- 앱 언어 및 홈 화면 앱 이름이 기기 언어에 맞게 표시되는지

## 2. Google Play 비공개 테스트 요건 확인
2023년 11월 13일 이후 생성된 개인 개발자 계정이라면 현재 Google Play 정책상 최소 12명의 테스터가 14일 연속으로 비공개 테스트에 참여 상태를 유지해야 프로덕션 액세스를 신청할 수 있다.

공식 안내:
https://support.google.com/googleplay/android-developer/answer/14151465?hl=ko

권장 운영:
- 정확히 12명보다 15~18명을 초대해 중도 이탈에 대비
- 테스트 시작일에 참여(opt-in) 여부를 확인
- 14일이 끝나기 전에 참여를 취소하지 않도록 안내
- 테스트 중 새 빌드를 올려도 테스터 참여 상태는 유지하되, Play Console에서 상태를 다시 확인
- 실제 사용 의견과 수정 내역을 기록해 프로덕션 액세스 신청 답변에 활용

## 3. 출시 전 필수 확인 — 개발자

### 빌드/배포
- [ ] 패키지명 `com.yakalimi.app` 확인
- [ ] versionCode / versionName 확인
- [ ] Play App Signing 및 업로드 키 전략 확인
- [ ] 프로덕션용 AdMob App ID / 배너 ID 적용 여부 확인
- [ ] `premium_unlock` 일회성 상품 생성 및 가격 ₩4,900 설정
- [ ] 개인정보처리방침 공개 URL 접속 확인
- [ ] 지원 이메일 `songseung88@hanmail.net` 확인

### Play Console
- [ ] 앱 이름과 설명 6개 언어 입력
- [ ] 개인정보처리방침 URL 입력
- [ ] 데이터 보안(Data safety) 작성
- [ ] 건강 앱 선언/의료 관련 항목 작성
- [ ] 전체화면 인텐트 사용 관련 선언 확인
- [ ] 콘텐츠 등급 설문 완료
- [ ] 광고 포함 여부 표시
- [ ] 앱 액세스 제한 없음 확인

## 4. 테스터 공통 시나리오
각 테스터는 아래 항목을 최소 1회씩 수행한다.

### A. 첫 실행
- [ ] 설치 후 앱이 정상 실행된다
- [ ] 알림 권한 안내가 이해하기 쉽다
- [ ] 필요한 권한을 허용/거부했을 때 앱이 비정상 종료되지 않는다
- [ ] 전체화면 알림 권한 안내가 필요한 기기에서 정상 표시된다

### B. 약 등록
- [ ] 약 이름을 입력해 첫 번째 약을 등록할 수 있다
- [ ] 하루 1회 복용 시간을 설정할 수 있다
- [ ] 하루 여러 회 복용 시간을 설정할 수 있다
- [ ] 재알림 간격을 설정할 수 있다
- [ ] 재고 수량과 저재고 기준을 설정할 수 있다

### C. 알림
- [ ] 화면이 켜진 상태에서 정시에 알림이 온다
- [ ] 화면이 꺼진 상태에서 알림이 온다
- [ ] 잠금화면에서 복약 알림을 확인할 수 있다
- [ ] 전체화면 알림 권한을 허용한 경우 기대한 방식으로 표시된다
- [ ] 소리/진동/무음 설정이 각각 의도대로 작동한다
- [ ] 알림을 놓쳤을 때 설정한 재알림이 동작한다

### D. 복용 기록과 재고
- [ ] ‘복용 완료’ 처리 후 기록에 반영된다
- [ ] 날짜별 복용 기록을 확인할 수 있다
- [ ] 복용 완료 시 재고가 의도한 만큼 줄어든다
- [ ] 저재고 기준에 도달하면 안내가 표시된다
- [ ] 실수로 처리했을 때 되돌리기/수정 흐름이 이해하기 쉽다

### E. 지속성
- [ ] 앱을 완전히 종료해도 다음 알림이 동작한다
- [ ] 휴대폰을 재부팅한 뒤에도 예약된 알림이 유지된다
- [ ] 자동 날짜/시간을 끄고 시간을 변경한 뒤 앱이 비정상 동작하지 않는다
- [ ] 시간대를 변경한 뒤 예약 시간이 합리적으로 유지된다
- [ ] 배터리 절약 모드에서도 가능한 범위에서 알림이 동작한다

### F. 무료/프리미엄
- [ ] 무료 상태에서 약 1개는 정상 등록된다
- [ ] 두 번째 약 추가 시 프리미엄 안내가 표시된다
- [ ] 프리미엄 설명에서 ‘1회 구매’임을 쉽게 이해할 수 있다
- [ ] ‘이전 구매 복구’의 의미가 이해된다
- [ ] Play 내부/비공개 테스트에서 구매 테스트 계정을 사용할 경우 구매와 복구가 정상 작동한다
- [ ] 프리미엄 상태에서는 광고가 제거되고 여러 약을 등록할 수 있다

### G. 설정/개인정보
- [ ] 개인정보처리방침을 누르면 공개 웹페이지가 열린다
- [ ] 의견 보내기를 누르면 이메일 앱이 열린다
- [ ] 광고 개인정보 설정 메뉴가 제공되는 환경에서는 정상 열린다
- [ ] 앱에서 입력한 복약 정보가 계정 가입이나 클라우드 전송을 요구하지 않는다

### H. 언어
가능한 테스터는 기기 언어를 바꿔 확인한다.

- [ ] 한국어: `약 알리미`
- [ ] 영어: `Medication Reminder`
- [ ] 일본어: `お薬リマインダー`
- [ ] 중국어(간체): `用药提醒`
- [ ] 힌디어: `दवा रिमाइंडर`
- [ ] 스페인어: `Recordatorio de medicación`
- [ ] 화면 문구가 잘리거나 버튼이 겹치지 않는다

## 5. 기기 분산 권장
12명 이상을 모집할 경우 가능한 한 아래가 섞이도록 한다.

- Android 13 / 14 / 15 / 16
- Samsung Galaxy 계열 다수 + 가능하면 Pixel 또는 다른 제조사 1~2대
- 작은 화면 / 큰 화면
- 다크 모드 사용자 포함
- 알림 소리 사용 / 진동 위주 / 무음 모드 사용자 포함

같은 모델만 12대로 채우는 것보다 서로 다른 Android 버전과 제조사를 섞는 것이 실제 오류를 찾는 데 유리하다.

## 7. 피드백 양식
테스터에게 아래 6가지만 받으면 충분하다.

1. 휴대폰 모델 / Android 버전
2. 가장 자주 사용한 기능
3. 알림이 오지 않거나 늦은 적이 있었는지
4. 이해하기 어려운 문구나 버튼이 있었는지
5. 앱 사용 중 오류/강제 종료가 있었는지
6. 가장 먼저 고쳤으면 하는 한 가지
